# C++ Fraction Class

A console program that models fractions with a C++ class and does arithmetic on them.

## What it does

- A `Drib` class (Ukrainian for fraction) with a numerator and a denominator
- Addition, subtraction, multiplication and division of two fractions
- Input from the keyboard, with a check that rejects a zero denominator
- Division by a zero fraction is caught and returns 0/1

## Built with

C++, Visual Studio

## Run

Open `Homework 19.04.2025 Task.sln` in Visual Studio and press Ctrl+F5.
